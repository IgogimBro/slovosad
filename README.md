# Словосад

Локальное приложение для практики русского чтения и правописания. React, TypeScript, Vite, Tailwind CSS, React Router, IndexedDB, Recharts, Web Speech API и PWA. Аккаунт и сервер для данных не нужны.

## Запуск готовой сборки

В папке проекта уже есть `dist/`. Нужен Node.js 22+ (проверенная версия — 24.19.0).

```powershell
node scripts/serve.mjs
```

Откройте **http://127.0.0.1:4173/**. Остановка сервера: Ctrl+C. На Windows также можно запустить `Start-Slovosad.ps1`: он найдёт Node в PATH или в установленном runtime Codex. Этот сервер предназначен для локального просмотра.

Не открывайте `dist/index.html` двойным щелчком: IndexedDB и service worker требуют веб-адреса.

## Разработка и проверки

Установите Node.js 22+ и pnpm 11. В обычной установке Node менеджер можно поставить командой `npm install -g pnpm@11`.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Адрес разработки: http://127.0.0.1:5173/. Для production PWA:

```sh
pnpm build
node scripts/serve.mjs
```

```sh
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```

Зависимости фиксирует `pnpm-lock.yaml`; разрешён необходимый install-скрипт esbuild. Форматирование: `pnpm exec prettier --write src tests`.

## Как начать

1. На главном экране выберите игру. Нажмите «Послушать слово»: браузеры требуют пользовательский жест для звука.
2. Выбирайте или составляйте ответ. Ошибки не убирают варианты и не раскрывают решение. Количество попыток не ограничено.
3. «Следующий вопрос» доступен только после полного решения. Переход всегда выполняется вручную.
4. «В сад» сохраняет занятие. Можно вернуться к той же игре и продолжить текущий вопрос, включая заполненные пропуски, выбранные плитки и правки редактора. Неотправленные черновики не считаются попытками.
5. Кабинет родителя открывается через арифметический пример. Это защита от случайного нажатия, не аутентификация. В «Настройках» выберите уровень, 2–4 варианта, длину занятия, категории, игры, подсказки, награды, скорость и громкость речи.

Игры: выбор написания, один/два пропуска, составление из плиток и редактор ошибок с добавлением, удалением и заменой букв. Каждая плитка имеет свою идентичность: одинаковые буквы можно использовать независимо. Начальное исправление содержит одну ошибку; для продвинутого уровня предусмотрены сложные варианты.

Если русского голоса нет, ребёнок может запросить помощь взрослого. После входа в кабинет откройте «Настройки»: там показаны слова незаконченных вопросов с отмеченной помощью. Произнесите слово, не показывая ребёнку написание. Приложение предпочитает локальный русский голос. При быстром повторе предыдущая озвучка отменяется. Гарантии офлайн-озвучки на всех iPhone нет: список голосов зависит от устройства ([Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)).

## Словарь и метрики

110 слов в десяти категориях. Неверные написания заданы явно. Ё и Е различаются. Новые слова добавляются в кабинете; категория может быть новой. Без трёх проверенных неверных написаний используйте только составление и пропуски. Проверка исключает дубликаты и настоящие слова из собственной библиотеки, но не заменяет проверку взрослым по полному русскому словарю. Архивирование убирает слово из новых упражнений, сохраняя историю. Изменённые родителем слова защищены от перезаписи обновлением библиотеки.

Безударную гласную не всегда можно определить по произношению: упражнения также тренируют запоминание написания.

Каждая попытка хранит ID профиля, занятия, вопроса и слова; режим и сложность; показанный текст и варианты; номер, точный ответ и результат; категорию ошибки; времена; дату; использованные до ответа подсказку и помощь. Для пропусков дополнительно записывается позиция. Все показатели получаются из настоящих локальных записей.

- **Завершение**: вопрос полностью решён независимо от количества попыток.
- **Точность с первой попытки**: доля завершённых вопросов без ошибок при первом ответе на каждую часть. У двух пропусков два первых ответа. Незавершённые вопросы показаны отдельно и в этот знаменатель не входят.
- **Точность попыток**: все верные ответы / все попытки, включая повторные ошибки.
- **Попытки до решения**, среднее и медианное время: только завершённые вопросы. Для двух пропусков нужно минимум две попытки.
- **Помощь** сравнивается отдельно: верный ответ с подсказкой не считается самостоятельным усвоением.
- **Повторение навыка**: самостоятельные решения в разных занятиях. Недавнее улучшение показывается только при наличии 6 завершений в минимум 3 занятиях. Такое сравнение — наблюдение, а не доказательство усвоения.

Активное время измеряется `performance.now()` и суммируется после возобновления; скрытая вкладка и пауза не считаются. Ответ и состояние вопроса сохраняются одной транзакцией IndexedDB. Время без ответа сохраняется каждые 2 секунды: при аварийном завершении процесса может потеряться до двух последних секунд, но подтверждённые записи попыток сохраняются.

Адаптация: больше ошибок, помощь, заметно более длительные ответы и срок повторения повышают вес слова. Интервалы самостоятельного повторения в разных занятиях: 1, 3, 7, 14, 30 дней. При достаточном пуле два последних слова не повторяются сразу. Сложность задаёт родитель.

## Размещение для iPhone

Для GitHub Pages подготовлена папка `docs/` и команда `pnpm build:pages`. Пошаговая публикация и обновления описаны в [GITHUB-PAGES.md](GITHUB-PAGES.md).

1. Выполните `pnpm build`, либо используйте готовую папку `dist`.
2. Разместите **содержимое** `dist` на статическом HTTPS-хостинге. Backend и база на сервере не нужны. `index.html`, `sw.js`, `workbox-*.js`, manifest, иконки и `assets/` должны быть доступны с одного адреса. Для `sw.js` и `index.html` используйте `Cache-Control: no-cache`; для файлов `assets/` с хешем допустимо длительное кеширование.
3. Откройте HTTPS-адрес в Safari на iPhone. Через «Поделиться» выберите «На экран Домой», включите «Открывать как веб-приложение», если такая настройка есть, и добавьте значок. [Инструкция Apple](https://support.apple.com/guide/iphone/iphea86e5236/ios).
4. Дождитесь сообщения «Офлайн-версия готова», откройте приложение ещё раз, затем проверьте его в авиарежиме. Проверьте отдельно русский голос. Если он не работает без сети, взрослый может произносить слово.

HashRouter позволяет размещать приложение в подпапке без серверных правил маршрутизации. При изменении домена/порта/браузера история не переносится; CSV — экспорт, а не импортируемая резервная копия. Сам код можно разместить публично: историю он не передаёт.

Service worker кеширует приложение, встроенные слова находятся в JS, а пользовательский словарь и история — в IndexedDB. Новую версию применяют вручную на главном экране; игра не перезагружается автоматически. Режим разработки не предназначен для проверки офлайн.

## Приватность и расширение

Нет рекламы, трекеров, внешних шрифтов, аккаунтов или загрузки истории. Браузер/ОС может использовать сетевой синтез речи для текста слова. Очистка данных сайта может удалить историю; регулярно экспортируйте CSV. В кабинете «Попытки CSV» выгружает каждый ответ, а «Вопросы CSV» включает также незаконченные вопросы без ответов. Родитель может создать профили, переключаться между ними и удалить историю выбранного профиля после подтверждения «УДАЛИТЬ».

Модули `src/core/`: типы, слова, генерация вопросов, переходы, хранилище, часы, озвучка, аналитика и адаптация. Представление — в `components/` и `pages/`. Новому режиму нужны генератор, правило ответа, метаданные режима и компонент. История содержит `profileId`; будущую синхронизацию можно добавить адаптером хранилища. Перед облаком понадобятся согласие родителей и модель доступа. Дополнительные языки, облако и аккаунты относятся к следующему этапу; UI пока русскоязычный.

## Проверка и ограничения

Результаты проверки — в `QA.md`. Реальный iPhone/Safari/VoiceOver и физические touch-жесты не проверялись. Размер экрана в настольном браузере — проверка вёрстки, а не проверка устройства. Независимая лингвистическая экспертиза не проводилась. Контент можно исправлять в кабинете без изменения движка.
